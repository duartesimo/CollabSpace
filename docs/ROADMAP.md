# Roadmap

High-level phases for CollabSpace. Details will be refined as development progresses.

## Phase 0 — Repository setup

- [x] Initial documentation and repository metadata
- [ ] Monorepo scaffold (backend, frontend, Docker Compose)
- [ ] Local development instructions in README

## Phase 1 — Backend foundation

- [ ] Spring Boot project with Java 21 and Maven
- [ ] PostgreSQL connection and base configuration
- [ ] Feature-based package structure

## Phase 2 — Frontend foundation

- [ ] React + TypeScript + Tailwind CSS scaffold
- [ ] API client and dev proxy to backend
- [ ] Basic layout shell

## Phase 3 — Core domain

- [ ] Users and authentication
- [ ] Teams, members, invites, and join requests
- [ ] Tasks and task assignments
- [ ] Friend requests and friendships
- [ ] Direct and team messages
- [ ] Notifications
- [ ] File metadata and uploads

## Phase 4 — Polish

- [ ] Tests for critical paths
- [ ] Error handling and validation
- [ ] Documentation updates

---

*Phases may be reordered or split as implementation progresses, but the core domain scope above reflects the full feature set of the original app.*
